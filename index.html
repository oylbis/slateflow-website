Les addonsThe add-ons

Six outils, une façon de travaillerSix tools, one way of working

Chaque addon facilite et fluidifie la production de trois procédés différents : montage, storyboard et animation 2D. Même s'ils peuvent être utilisés indépendament, ils couvrent ensemble tout ce pan de fabrication : du premier plan de storyboard au montage final exporté vers Resolve.

Each add-on makes production easier and smoother across three different crafts: editing, storyboard and 2D animation. They can be used independently, but together they cover this whole side of production, from the first storyboard shot to the final edit exported to Resolve.

Le problème sans sequencerFlowThe problem without sequencerFlow
Le VSE natif de Blender est fonctionnel mais austère : peu de retour visuel, pas de montage 3 points intégré, aucune vue directe des courbes d'animation posées sur un strip, et l'organisation de nombreux strips devient vite confuse sans repères visuels dédiés.
Blender's native VSE works but is austere: little visual feedback, no built-in 3-point editing, no direct view of animation curves on a strip, and organising many strips quickly becomes confusing without dedicated visual guides.
Barre d'outils contextuelleContextual toolbar

Un montage sans naviguer dans les menus. Les outils :

  • Cut — coupe classique d'un ou plusieurs strips sélectionnés par le timeline cursor
  • Join — recoudre deux strips coupés qui se succèdent
  • Swap left/right — intervertir deux plans en conservant la sélection
  • Slip — déplacer la source dans les bornes du strip
  • Insert (PRO) — insérer un strip édité dans le montage principal
  • Connect/disconnect — avec écriture de métadatas pour l'export OTIO
  • Sélections avancées — left/right/up/down/channel + selection sets
  • Isolates — channel ou strip, réversibles
  • Ranges — selected/all/auto
  • Follow playhead — le montage suit la tête de lecture

Edit without digging through menus. The tools:

  • Cut — classic cut of one or more selected strips at the timeline cursor
  • Join — stitch back two consecutive cut strips
  • Swap left/right — swap two shots while keeping the selection
  • Slip — move the source within the strip's bounds
  • Insert (PRO) — insert an edited strip into the main edit
  • Connect/disconnect — writes metadata for OTIO export
  • Advanced selections — left/right/up/down/channel + selection sets
  • Isolates — channel or strip, reversible
  • Ranges — selected/all/auto
  • Follow playhead — the edit follows the playhead

A dedicated preview window to load a media, set in/out points, then insert it into the edit with automatic ripple of everything after — exactly like in a professional NLE.

Le problème sans sequencerOTIOThe problem without sequencerOTIO
Blender ne couvre pas tout (mixage son avancé, étalonnage pro, export DCP…). Transférer proprement un montage Blender vers Resolve — pistes, vitesse, fondus, liens vidéo/son — demandait un travail manuel fastidieux et sujet à erreur, sans parler du retour en arrière quand Resolve modifie le montage.
Blender doesn't cover everything (advanced audio mixing, pro colour grading, DCP export…). Moving a Blender edit to Resolve properly — tracks, speed, fades, video/audio links — used to mean tedious, error-prone manual work, never mind going back when Resolve changes the edit.
Export optimisé pour ResolveResolve-optimised export
Construit un fichier .otio multi-piste fidèle au montage Blender : liens vidéo/audio, keyframes de volume/opacité converties en courbes de Bézier, fondus natifs, vitesse et freeze frame, transforms.
Builds a multi-track .otio file faithful to the Blender edit: video/audio links, volume/opacity keyframes converted to Bézier curves, native fades, speed and freeze frames, transforms.
Import depuis Resolve & mode ConformImport from Resolve & Conform mode
Trois façons de récupérer un .otio : l'ajouter au montage existant, le remplacer entièrement, ou le comparer intelligemment. Le mode Conform classe chaque plan (inchangé, déplacé, retrimé, split, modifié, créé, supprimé) et applique uniquement les changements réels — jamais un écrasement aveugle du travail déjà fait.
Three ways to bring a .otio back in: add it to the current edit, fully replace it, or compare it intelligently. Conform mode classifies each shot (unchanged, moved, retrimmed, split, modified, created, deleted) and applies only the real changes — never blindly overwriting existing work.
Zéro configurationZero configuration
La librairie OpenTimelineIO est fournie avec l'addon et installée automatiquement au premier lancement. Une connexion réseau n'est nécessaire qu'en dernier recours, si aucune version pré-fournie ne correspond à la plateforme.
The OpenTimelineIO library ships with the add-on and installs automatically on first launch. A network connection is only needed as a last resort, if no bundled version matches your platform.
